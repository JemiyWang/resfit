## 2. ② 是什么(已实现,无需改代码)

- **②a 残差 demo-BC**(`--demo_bc_coef`):给残差 actor 加一个 BC 正则项,把残差锚向"演示残差"
  (target = 实际动作 − base 动作)。bc_batch 默认从 GT demo(offline_rb)采。值即 BC 权重,默认 0=关。
- **②b 在线 relabel**(`--relabel`):训练循环里 harvest 失败但推进过 stage 的 rollout 的"产出前缀"段
  (起点→最后一次 stage 推进,丢卡住的尾巴),进 relabel buffer 当正样本;bc_batch 改为 relabel+demo 50/50 混采。
  只喂 actor 侧 BC,**不碰 critic**(避开"喂单任务 critic 加重高估"红线)。
- 关键依赖:`--relabel` 需 `--demo_bc_coef>0` + `--offline_fraction>0` + `--actor raw`(都有断言)。
- 代码:`chunk_residual/relabel.py`、`off_policy/rl/q_agent.py`(bc_target + 解 assert)、
  `train_chunk_residual.py`(flag + 接线)。spec/plan 见
  `docs/superpowers/specs(plans)/2026-06-06-residual-demo-bc-*` 与 `2026-06-06-relabel-harvest-*`。

## 4. 跑哪几臂 + 命令(可直接照搬)

强 base config = nas10 那套(`--base_n_action_steps 10` + offline 锚 0.5 + staged + cl=1 queue + actor raw),
与 budget A 完全一致,只在臂间加 ② 的 flag。`<gpu>` 选空闲卡;两臂各占一张卡并行最好。

### B run —— ②a demo-only(只加 demo-BC 锚,验证"demo 锚有没有用")
```bash
CUDA_VISIBLE_DEVICES=<gpu> MUJOCO_GL=egl PYOPENGL_PLATFORM=egl \
conda run -n residual --no-capture-output python -u \
  -m resfit.rl_finetuning.chunk_residual.train_chunk_residual \
  --task TwoArmThreePieceAssembly \
  --base_wandb_id dexmg-threepiece-bc/7zklm69g \
  --dataset ankile/dexmg-two-arm-three-piece-assembly \
  --chunk_length 1 --base_action_mode queue --base_n_action_steps 10 \
  --reward_shaping staged --stage_reward_bonus 1.0 \
  --action_scale 0.05 --actor_lr 1e-6 --stage_balanced --actor raw \
  --offline_dataset_path deps/dexmimicgen/datasets/generated/two_arm_three_piece_assembly.hdf5 \
  --offline_fraction 0.5 --offline_stage_cache outputs_chunk/three_piece_stages.npz \
  --demo_bc_coef 0.1 \
  --wandb_project dexmg-chunk-residual --wandb_name nas10_best_demobc0.1 \
  --output_dir outputs_chunk/nas10_best_demobc0.1 \
  2>&1 | tee nas10_best_demobc0.1.log
```

### C run —— ②b relabel(在 B 基础上开 relabel,验证"收部分成功有没有用")
在 B 的所有行基础上,把最后三行换成:
```bash
  --demo_bc_coef 0.1 --relabel \
  --wandb_project dexmg-chunk-residual --wandb_name nas10_best_relabel \
  --output_dir outputs_chunk/nas10_best_relabel \
```

(`--relabel_buffer_size 50000`、`--relabel_min_stage 1` 用默认即可;想只收走得远的轨迹再调高 min_stage。)
