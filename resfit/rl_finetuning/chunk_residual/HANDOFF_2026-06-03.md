## 2. stage-purity 诊断(本轮新增的核心工具)

### 实现
- `chunk_env_wrapper.py`:跨 episode 累计 `瞬时 stage s < 闩锁 stage L` 的回退事件,按桶统计。
  新增字段 `_stage_total_steps / _stage_regress_steps / _steps_by_latch / _regress_by_latch` 和
  方法 `stage_purity_summary()`。
- `train_chunk_residual.py`:每次 eval 多打一行 `[stage-purity] ...`。

### 结果(staged_as0.05, ~40k)
```
[stage-purity] regress 15641/39920=39.2%
  stage0:  0%
  stage1: 45%
  stage2: 32%
  stage3: 76%   ←←←
```
**stage3 桶 76% 是掉件退化样本**(闩锁标 3,瞬时已退回 2)。物理含义:agent 抓起 piece_2 后,
在"叠准 piece_1 上方 + 下压 + 精准松手"这步反复失败/掉件——正是全任务最精细的闭环微调环节。

### 影响
- 这是"残差破坏 stage3"诊断的硬证据。
- **若做 stage-conditioning,必须先解耦闩锁**:reward 继续用闩锁阶段(防刷分),
  但 `obs.stage_id`(喂 actor + stage-balanced 采样)改用**瞬时阶段**,否则 stage3 输入标签 76% 是错的。
  实现很轻:wrapper 里同时维护 `self._stage`(闩锁)和 `self._stage_now`(瞬时)。

## 3. 诊断认知(本轮厘清,避免后人再踩)

- **target_q 按 stage 递减(0>1>2>3,到 −2.5)不是 critic 学反**,而是 potential 整形的恒等式
  `Q_整形 = Q_原始 − bonus·Φ(s)` 造成的 −stage 平移。**对策略完全无害**(同状态内所有动作减同一常数,
  advantage 不变 / actor 的 −Q 梯度对它导数为 0)。把偏移加回去,stage3 反而最高(~0.5),符合直觉。
  → **不要在 loss 里"修正"它**;想画图顺眼就在打印时加回 Φ。
- **成功信号只从 (stage3→成功) 这一条 done 边进入 Q**,再靠 bootstrap 接力往前段传。
  残差一破坏 stage3 → 该边很少点亮(源头干涸)+ Q(stage3) 被失败样本拉低(中继变质)→ 全链悲观 → 塌。
  **病灶在 actor 残差,不在 critic / reward / 接力链。**
- **原始 env reward 纯稀疏**(`reward()` 里只有 `if _check_success(): reward=1.0`,dense 项是空 stub)。
  staged = 每跨阶净 +1(闩锁保住),成功步 +2;potential = 每步给分(停留税 −0.1·L / 推进 +0.9-0.1L /
  成功步 −3 叠原始 +1 = −2,且**截断 truncation 也置 Φ'=0 → 高阶段超时被重罚 −L**,是个坑)。
- **PBS 对"部分进度"的净激励 = 0**(爬升奖被抵消),只加速稀疏信号传播、不增加"够到中间阶段"的吸引力。
  想要净进度激励是 staged(但会改最优策略、有刷分风险)。**提高成功奖励(+1→+4)不改最优策略、修不了塌,
  纯化妆。** 真正缺的是 demo 锚。
